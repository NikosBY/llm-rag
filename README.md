# German RAG Assistant

Retrieval-augmented Q&A over a German corpus with proper evaluation
(recall@k, faithfulness, answer relevance), served as a Gradio chat Space.
LoRA fine-tune of Qwen2.5-1.5B included.

> WIP — pipeline and evaluation in progress.

uv venv .venv && uv pip install -e .
